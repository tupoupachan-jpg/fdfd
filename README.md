# Telegram-бот для уведомлений о заменах расписания

Бот проверяет страницу колледжа с заменами: https://www.auto-meh.ru/student/zameni/ и отправляет уведомление подписчикам, если содержимое страницы изменилось.

## Куда вставлять токен

Токен вставляется в файл `.env` в строку `BOT_TOKEN`.

1. Скопируйте шаблон:
   ```bash
   cp .env.example .env
   ```
2. Откройте файл `.env` в любом текстовом редакторе.
3. Замените строку:
   ```env
   BOT_TOKEN=your_telegram_bot_token
   ```
   на ваш токен от `@BotFather`, например:
   ```env
   BOT_TOKEN=123456789:AA...ваш_токен...
   ```

> Бот автоматически читает `.env` при запуске, поэтому достаточно просто выполнить `python bot.py`.

## Что умеет

- Подписка на уведомления: `/start`
- Отписка: `/stop`
- Ручная проверка страницы: `/check`
- Статус бота: `/status`

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

После этого заполните `BOT_TOKEN` в `.env` и запустите:

```bash
python bot.py
```

## Как это работает

1. Бот раз в `CHECK_INTERVAL_SECONDS` скачивает страницу замен.
2. Извлекает текст страницы и считает SHA-256 хэш.
3. Сравнивает с предыдущим хэшем, сохранённым в `state.json`.
4. Если хэш изменился — отправляет уведомление всем подписчикам.

## Примечания

- При первом запуске бот просто запоминает текущее состояние страницы (без рассылки).
- Если сайт временно недоступен, бот пишет ошибку в лог и продолжает проверки.
